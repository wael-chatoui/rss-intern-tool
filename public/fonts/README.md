# PDF export fonts

Noto Sans Regular, Bold and Noto Sans Symbols 2 are from the Noto Project:
https://github.com/notofonts/noto-fonts

Noto Emoji Regular is the static weight-400 instance of the official Noto Emoji variable font:
https://github.com/google/fonts/tree/main/ofl/notoemoji

The static instance retains the source font's outlines and is used without subsetting because emoji glyphs disappeared in subset PDFs during visual verification. The application does not require Python or FontTools at runtime.
